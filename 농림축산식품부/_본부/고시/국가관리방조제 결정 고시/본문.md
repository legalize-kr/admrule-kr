# 국가관리방조제 결정 고시

○ 방조제명 : 고흥만방조제, 사내방조제
  ○ 소 재 지
    - 고흥만방조제 : 전남 고흥군 두원면 풍류리 ↔ 도덕면 용동리
    - 사내방조제 : 전남 강진군 신전면 사초/용화리 ↔ 해남군 북일면 내동/용일/신원리
  ○ 주요시설
    - 고흥만방조제 : 방조제 1조 2,873m, 제정폭 12.5m,                    배수갑문 1개소(폭6.5m×높이5.8m×4련)
    - 사내방조제 : 방조제 1조 3,260m(평균높이 2.5m, 제정폭 3.0m),   배수갑문 1개소(폭4.0m×높이3.0m×6련)
  ○ 포용조수량
    - 고흥만방조제 : 88,980천㎥,  사내방조제 : 15,050천㎥
  ○ 소 유 자 : 국가(농림축산식품부)
  ○ 원관리자 및 관리대행자 :
    - 고흥만방조제 : 고흥군수, 사내방조제 : 강진군수
