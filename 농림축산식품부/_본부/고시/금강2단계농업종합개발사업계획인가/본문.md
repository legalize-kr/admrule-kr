# 금강2단계농업종합개발사업계획인가

  1\. 사업지구명 : 금강(II)지구 농업종합개발사업

  2\. 사업목적 : 농업기반조성, 식량증산, 농가소득증대, 영농환경개선

  3\. 사업구역

           서천군 장항, 서청읍
                  마서, 화양, 기산, 환산, 마산, 시초, 문산, 종천면
  전라북도 군산, 김제시
           완주군 삼례, 봉동읍
                  용진, 이서, 고산, 비봉, 화산면
           김제군 죽산, 백산, 용지, 백구, 만경, 공덕, 청하, 성덕, 진봉, 금구, 봉남, 황산, 광활면
           옥구군 옥구읍
                  옥산, 회현, 임피, 서수, 대야, 개정, 성산, 나포면
           익산군 오산, 황등, 함라, 옹포, 낭산, 금마, 왕궁, 춘포, 삼기면

  4\. 사업면적 : 개발면적 43,000ha

  5\. 사업시행자명: 농업진흥공사사장

  6\. 주요사업개요 : - 양 수 장 : 9개소
                  - 용 수 로 : 696km
                  - 경지정리 : 4,723ha
                  - 배수개선 : 11,988ha

  7\. 총사업비 : 4,158억원

  8\. 사업효과 : - 미곡증산(년간) : 74,906M/T
              - 경지이용율 : 107% -> 145%
              - 투자수익율 : 16.6%

  9\. 사업기간 : 1989년 ~ 2004년(16개년)

  10\. 개발하고자 하는 토지의 위치와 필지수 : 충남 서천군 화양면 옥포리 447번지외 285, 295필지

  11\. 관계도서는 농업진흥공사 금강사업소에 비치하고 이해관계인의 열람에 공한다(수용 또는 사용할 토지등의 세목 및 권리의 명세서, 관계도면은 게재 생략).
