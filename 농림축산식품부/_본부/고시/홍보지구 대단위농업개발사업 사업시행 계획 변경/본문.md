# 홍보지구 대단위농업개발사업 사업시행 계획 변경

  1\. 사 업 종 류 : 농업생산기반정비사업 (변경 없음)

  2\. 사업지구명 : 홍보지구 대단위농업개발사업  (변경 없음)

  3\. 사업목적 : 수자원확보, 농업기반조성 (변경 없음)

  4\. 사업구역 : 변경 없음
  ○ 1도 1시 1군 14개 읍·면
  ○ 충청남도 홍성군 홍성·광천읍, 서부·결성·구항·장곡·은하·홍동·갈산면,  보령시 오천·천북·주포·주교·청소면

  5\. 개발면적 : 8,100ha (변경 없음)

  6\. 사업시행자 (명칭 변경)
  ○ 당초 : 농업기반공사 사장,   ○ 변경 : 한국농어촌공사 사장

  7\. 주요사업개요
  ○ 당초 : 방조제 2개소 2.9km,  배수갑문 2개소, 도로 14.0km, 양수장 6개소, 용수로 365km, 경지정리 1,060ha, 배수개선 725ha
  ○ 변경 : 방조제 2개소 2.9km,  배수갑문 2개소, 도로 14.0km, 양수장 6개소, 용수로 365km, 경지정리(삭제), 배수개선 1,070ha

  8\. 총사업비 : (당초) : 3,812억원,   (변경) : 4,235억원

  9\. 사업기간 : (당초) : 1991년~2010년(20개년),  (변경) : 1991년~2016년(26개년)

  10\. 사업효과 : 수자원 32백만톤 확보, 도로 16.9km 신설 (변경 없음)

  11\. 수용 및 사용하고자 할 토지, 물건, 권리 등의 세목조서 : 별도 고시 예정

  12\. 참고사항 : 관계도서는 한국농어촌공사 천수만사업단(041-630-5823)에 비치하고 이해관계인에게 보입니다
