# 영산강3-2단계농업종합개발사업계획인가

  1\. 사업지구명 : 영산강유역(III-2) 단계 대단위 농업종합개발사업

  2\. 사업목적 : 수자원 확보, 농경지 확장, 식량증산, 농가소득 증대

  3\. 사업구역 : 전라남도 해남군 산이, 황산, 문내, 화원면 지선

  4\. 사업면적 : 개발면적 6,800ha

  5\. 사업시행자명: 농업진흥공사사장

  6\. 주요사업개요
  - 담 수 호 : 1개소
  - 방 조 제 : 2조 2,120m
  - 배수갑문 : 1개소 10m X 10.5m X 4련
  - 제엽암거 : D=2.2m L=435m 4련
  - 연락수로 : 2조 11,373m
  - 도    로 : 6조 10,531m

  7\. 총사업비 : 164,000백만원

  8\. 사업효과
    가\. 직접효과
    ○ 수자원확보 : 133.1백만톤 (유효저수량 75.5백만톤)
    ○ 농경지확장 : 3,910ha
    ○ 식량증산 : 28,772M/T
    ○ 농가소득증대
    나\. 간접효과
    ○ 국토확장 : 7,433ha
    ○ 육운개선 : 목포 -> 진도간 41km단축
    ○ 국민휴식공간 및 관광자원조성

  9\. 사업기간 : 1989년 ~ 1998년(10개년)

  10\. 개발하고자 하는 토지의 위치와 필지수 : 전남 해남군 황산면 일신리 118-5번지외 19,056필지

  11\. 관계도서는 농업진흥공사 영산강삼단계 사업소에 비치하고 이해관계인의 열람에 공한다(수용 또는 사용할 토지등의 세목 및 권리의 명세서, 관계도면은 게재 생략).
