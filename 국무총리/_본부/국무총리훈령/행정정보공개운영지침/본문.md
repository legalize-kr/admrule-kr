# 행정정보공개운영지침

  1\. 목적
  ○국민의 알권리 충족과 행정의 신뢰성을 두텁게 하기 위하여 행정기관이 보유·관리하고 있는 정보를 일반 국민에게 공개함.
  ○행정정보공개법이 제정되기 전까지 제도의 효율적 운영을 위한 내부기반을 구축하여 시행여건을 사전에 조성하고
  ○행정정보공개제도 운영에 관한 일반적인 기준과 절차를 정립, 운영함으로써 정보공개에 관한 운영경험을 축적하려는 것임.

+----------------┤  행정정보공개제도 개요  ├------------------+
|                └-------------------------┘                  |
|  ○제도개념                                                   |

|  ○도입배경                                                   |
|    -국정에 대한 국민의 알권리 주장과 투명한 공개행정 필요     |

|    -청구공개 : 일반인의 신청에 의하여 공개하는 형태           |
|              (예 : 정부공문서의 열람청구등)                   |
|    -정보제공 : 행정기관이 스스로 정보를 제공하는 형태         |
|              (예 : 행정간행물의 배포등)                       |
+---------------------------------------------------------------+
  2\. 적용범위
    가\. 적용법령
    ○개별법령에서 행정정보공개에 관한 규정을 두고 있는 경우
      -당해 법령의 규정에 따라 정보를 공개하도록 함.
      ※개별법령에 구체적인 세부운영사항이 규정되어 있지 않는 경우에는 당해 법령규정에 저촉되지 않는 범위안에서 이 지침을 적용함.
    ○개별법령에 행정정보공개에 관한 규정이 없는 경우
      -이 지침을 적극 활용하도록 함.
    나\. 적용기관
    ○총무처장관 : 행정정보공개제도 추진에 관한 전반적인 사항을 총괄 운영
    ○중앙행정기관 : 이 지침을 직접 적용하여 운영
      ※당해 기관의 지휘·감독을 받는 공공단체에 대하여도 행정정보공개제도가 활성화될 수 있도록 적극 권장할 것
    ○지방자치단체 : 행정정보공개조례가 정하는 바에 따라 운영
      ※내무부장관·교육부장관은 행정정보공개에 관한 조례나 지침 등이 없는 지방자치단체의 경우에는 적극적으로 공개제도를 운영하도록 지도할 것
    다\. 대상정보
    ○행정기관이 공무상 작성 또는 취득하여 관리하고 있는 기록물을 대상으로 하되, 문서외에 도면·필름·디스크등 포함 : 사무관리규정 제3조 참조
      ※행정기관에서 관리하고 있는 자료중 직무수행과 관련이 없는 신문·잡지등 일반자료나 일반인에게 특정한 절차없이 자유로이 제공하기 위한 정보는 제외함.
  3\. 행정정보공개 시행기반 구축
                         ┌------------┐
+------------------------┤  추진방향  ├-----------------------+
|                        └------------┘                       |
|  ○행정정보공개제도는 대상정보의 신속한 색인·검색과 체계적   |
|    인 보존·관리등 공개를 위한 기반구축이 중요하므로,         |
|  ○각급기관은 행정정보공개법의 제정·시행에 대비하여 이 지    |
|    침에 따라 시행여건 조성을 적극 추진하도록 할 것            |
+---------------------------------------------------------------+
    가\. 행정정보의 체계적 분류
      (1) 정보내용별 분류
      ○행정정보를 생산하거나 취득한 때에는 아래 기준에 의하여 정확한 분류번호를 부여할 것.
        -공문서 : 공문서분류및보존에관한규칙(총리령)에 의하여 분류
        -공문서이외의 정보 : 사무관리규정(제85조)에 의하여 분류
        ※이하 이 지침에서 사무관리규정은 "규정"으로, 사무관리규정시행규칙은 "규칙"으로 표현함.
+---------<유의사항>--------------------------------------------+
|   각급기관에서 1992년 12월 31일이전에 생산 또는 접수하여 보   |
|   존하고 있는 문서를 당해 기관의 문서과 또는 정부기록보존소   |
|   에 이관할 때에는                                            |
|   -문서철(규칙 별지 제13호서식)에 편철된 개별문서에 표기되    |
|    어 있는 문서분류번호는 그대로 두되,                        |
|   -문서철의 표지(화일표지 또는 흑표지)의 앞면과 옆면에 표기   |
|    하는 분류번호는 1993년 1월 1일부터 시행하고 있는 공문서    |
|    분류 및보존에관한규칙(총리령)에 의한 분류번호로 표기하여   |
|    이관할 것                                                  |
+---------------------------------------------------------------+
      (2) 보존기간별 분류
      ○각급기관이 공문서(연구·검토보고서 포함)를 기안할 경우에는 반드시 "공문서분류및보존에관한규칙"에서 정한 보존기간(영구·준영구·10년·5년·3년·1년)을 책정·기재하도록 함.
        ※보존기간 책정기준 : 공문서분류및보존에관한규칙 별표 참조
+-----------------<보존기간책정 일반기준 : 예시>----------------+
|    ○영구 : 대규모의 예산이 투입되는 사업의 기본계획에 관     |
|      한 문서                                                  |
|    ○준영구 : 대규모사업계획 수립을 위해 작성한 중요 연       |
|      구·검토 문서                                            |
|      ※영구보존할 필요는 없으나 10년이상 보존필요가 있는      |
|        문서는 준영구로 분류                                   |
|    ○10년 : 각종 인·허가 및 면허등에 관한 원본문서           |
|    ○5년 : 예산·결산 및 회계관계 증빙문서                    |
|    ○3년 : 각종 증명서 발급이나 단기업무계획 관계문서         |
|    ○1년 : 일일명령이나 기관내 업무연락등 단순업무에 관한     |
|      문서                                                     |
+---------------------------------------------------------------+
      ○문서보존기간은 생산기관이 정하되, 접수기관의 보존기간은 특별한 사유가 없는 한 기안문서(생산기관 보존)보다 짧게 부여하여 시행할 수 있음.
      ○각급기관은 매년 1회 당해 기관에서 보존하고 있는 문서의 보존기간 변경 필요성 여부를 검토하여 연장 또는 단축할 수 있음.
        ※보존기간이 10년이하인 문서를 영구 또는 준영구문서로 기간을 연장하거나 영구·준영구문서에서 10년이하 문서로 단축하고자 할 경우에는 총무처장관과 사전협의할 것(공문서분류및보존에관한규칙 제7조)
    나\. 생산·수집 정보의 등록 관리
    ○행정기관이 생산한 공문서(내부결재문서 포함)는 결재가 끝난 즉시 결재일자 순에 따라 각 처리과별로 문서등록대장에 등록하여야 함.

       -대통령이 결재한 문서나 대통령에게 보고한 문서에 대하여는 관리번호를 부여하여 대통령결재문서관리대장(규칙 제20호서식)을 기록·유지해야 함.
       -공문서 첨부물로서 문서철에 합철하기 곤란한 인쇄물·책자등을 특수규격관리대장에 기록·관리할 수 있음.

        ※문서를 마이크로필름에 수록한 경우 문서 원본은 계속 보존하되, 이를 폐기한 때에는 마이크로필름에 수록한 문서를 보존중인 문서(원본)로 봄(규정 제30조제2항).
        ○수록대상문서 및 수록우선순위는 당해 기관의 활영능력, 보존가치, 활용빈도를 고려하여 결정하도록 함.
        ○문서를 마이크로필름에 수록하고자 할 때에는 필름문서 촬영책임자를 지정하고 별도로 마련한 촬영실에서 촬영하도록 함.
        ○문서를 마이크로필르에 수록한 때에는 마이크로필름 문서기록대장과 보존문서기록대장에 그 사실을 기재하여야 함.

        ※사무실 신축·증축계획을 수립할 때에는 반드시 문서보존실의 면적을 확보하도록 할 것

        ○행정정보 유통확대를 위한 보급망 확충
        -각급기관은 보유자료의 효율적인 관리·이용을 위하여 당해 기관내에 행정자료실을 설치하되, 전담인력과 소장자료목록을 비치하고 복사기·마이크로필름 판독기등 열람시설을 확보하여 나갈 것
        ※2이상의 행정기관이 동일청사를 이용할 경우 상호협의하여 합동청사자료실 운영 가능
        -행정간행물을 전국 어디서나 쉽게 구입할 수 있도록 정부간행물판매센타를 확대운영하고 행정자료실에 간행물 코너를 설치하여 일반국민의 이용을 활성화하도록 함.
        -각급기관은 보유하고 있는 정보에 대하여 다른기관의 정보제공요청이 있는 경우에는 적극 협조하고 행정간행물을 발간한 경우에는 행정자료기관에의 납본을 철저히 이행하도록 함(규정 제82조).
        ·납본기준 : 당해 기관 행정자료실 3부, 정부기록보존소 3부, 국립중앙도서관 3부, 각 시·도의 지역대표도서관 2부
        ※행정간행물이 아닌 행정자료도 관련기관이나 정부기록보존소 등에 당해 자료를 제공하여 일반인이 이용할 수 있도록 할 것.
        ○행정간행물의 판매·보급 확대
        -행정간행물을 발간할 때에는 실비제작가격을 책정하여 정부간행물 판매센타 또는 자체 행정자료실에서 일반인에게 제공하도록 함.
        ※종전에 비매품으로 지정하여 발간부수·배포기관을 한정한 간행물도 되도록 적정한 가격을 책정하여 일반인에 대한 제공을 확산할 것
        ○행정정보 이용·안내제도 확대
        -일반인이 행정정보의 소재파악을 용이하게 하기 위하여 당해 기관의 부서 기능을 안내하는 기관안내편람을 제작하여 정보공개 주관부서·민원실등에 비치하도록 함.
        ※기관안내편람 주요내용 : 기관명, 주소, 정보공개 주관부서, 부서별 세부기능 및 전화번호등과 영구·준영구 공문서중 생산된 지 6년이 경과된 문서는 원칙적으로 정부기록보존소에서 관리하게 됨을 안내
        -일반인이 행정정보공개제도를 쉽게 이용하게 하기 위하여 행정정보공개 청구기관, 청구절차, 수수료, 구제제도등 정보공개제도의 이용·안내에 관한 팜플렛을 정보주관부서나 민원실등에 비치 또는 제공하도록 함.
        -각급기관은 행정자료실 소장자료의 목록을 연 1회이상 정부기록보존소등 관련기관에 제공하도록 하고 일반국민에게 제공할 필요가 있는 정보(예 : 행정간행물)의 목록등을 전산화하여 행정종합정보망과 연결, 국민이 이용할 수 있도록 함.
        -정부보존기록물에 대한 주기적 전시와 기록물 목록을 발간·배포하고 신문·방송등 대중매체와 관보·국정신문등에 정보공개제도의 이용방법등에 관한 홍보를 강화하도록 함.

        ※주관부서와 처리과는 정보공개 처리상황을 파악하기 위하여 행정정보공개처리대장(별지서식 2 참조)을 작성·관리할 것

        ·특정정보의 공개·비공개에 관한 자문
        ·행정정보공개제도 운영에 관한 의견 제공
        ※현재 행정정보공개심의회와 유사한 기능을 수행하는 기구가 설치되어 있는 경우에는 기존 기구 활용가능
        ○청구받은 정보가 다른기관이나 제3자와 관련된 정보로서 관계기관 또는 제3자의 공개여부에 대한 의견을 수렴할 필요가 있는 경우에는 사전에 당해 기관 또는 제3자의 의견을 들어 처리하도록 함.
        (예) 다른기관이 생산산 문서, 제3자의 권익과 관련된 문서등
        ※정부기록보존소가 보존하고 있는 문서에 대한 공개여부를 자체적으로 판단하기 곤란한 경우에는 생산기관에 의견을 조회하여 처리할 것.
        (2) 정보공개 운영
        ○정보공개 원칙
        -각급 행정기관은 행정정보공개제도가 국정운영에 대한 국민의 이해를 증진시키고 행정의 신뢰성·공정성을 확보한다는 점을 인식하고
        -당해 기관이 보유하고 있는 행정정보는 특별한 사유가 없는 한 공개하여 국민의 알권리가 최대한 존중될 수 있도록 할 것.
        ○공개제외 대상
        -청구인이 공개를 요청한 정보가 다음 각호의 1에 해당하는 정보일 경우에는 공개를 하지 않을 수 있음.
        ·보안업무규정이나 다른 법령등에 의하여 비밀로 지정되거나 비공개사항으로 규정된 정보
        ·공개할 경우 국가안전이나 국방 또는 외교관계를 해한다고 인정되는 정보
        ·범죄의 예방·수사·소추·형의집행·교정·보안처분에 관한 정보로서 공개할 경우 직무수행이 현저히 곤란하거나 공정한 재판을 받을 권리를 침해하는 정보
        ·인격·신분·종교·재산·경력등 개인에 관한 사항으로서 공개할 경우 개인의 사생활을 침해할 우려가 있는 정보
        ·사람의 생명 또는 신체의 안전에 관한 정보로서 공개할 경우 생명·신체·자유·건강등에 대한 침해가 우려되는 정보
        ·법인이나 사업자등의 영업 또는 과학기술이나 금융에 관한 정보로서 공개함으로써 사업운영상 지장을 초래하는 정보
        ·비공개를 전제로 제3자(기관·단체등)로부터 취득한 정보
        ·행정기관에서 의사결정 또는 정책결정과정에 있는 사항으로서 공개할 경우 의사결정등에 지장을 초래하는 정보
        ·행정기관 내부의 인사에 관한 사항으로서 공개할 경우 공정한 인사관리에 지장을 초래하는 정보
        ·기타 공개할 경우 특정인에게 이익·불이익을 주는 정보 또는 행정의 공정·원활한 집행이나 공공의 이익을 현저히 해한다고 판단되는 정보
        ※공개에 따른 행정기관의 비용부담이 지나치게 과중하거나 공개요구자료가 과다하여 공개가 현실적으로 어려운 경우 또는 공개청구목적이 공개제도의 취지에 벗어나는 경우에는 사안별로 판단·결정할 것
        ○공개청구를 받은 정보의 내용중 공개할 수 없는 정보와 공개할 수 있는 정보가 혼합되어 있는 경우에는
        -공개할 수 있는 부분을 용이하게 분리할 수 있을 뿐만 아니라 분리를 하여도 공개청구의 취지가 손상되지 않는다고 인정되는 때에는 공개할 수 있는 부분만을 분리하여 공개할 수 있음.
        ○행정정보를 비밀로 분류할 때에는 당해 비밀을 적절히 보호할 수 있는 최저등급으로 분류하되, 과도 또는 과소하게 분류하지 않도록 함.
        -비밀을 접수한 기관이 그 비밀을 검토한 결과 과도하게 분류되었다고 인정될 때에는 그 사유를 명시하여 발행기관에 재분류를 요청하여 적정하게 분류할 것
    라\. 공개·비공개 결정 통지
        ○공개요구받은 정보를 담당하는 처리과의 장은 공개·비공개 여부를 결정한 때에는 그 사실을 즉시 청구인에게 통지하고(별지서식 3<%생략:서식3%> 참조) 그 사실을 주관부서의 장에게 통보하도록 함.
        -공개결정 통지 : 공개일시, 장소, 방법 및 수수료금액, 납부방법등 명시
        ※청구인이 요구하는 정보가 정부간행물 판매센터 또는 공공도서관등에서 구입·열람가능한 정보인 경우에는 그 사실을 기재하여 구입·열람토록 조치
        -비공개결정 통지 : 공개할 수 없는 사유와 이에 불복할 경우 행정심판을 제기할 수 있다는 취지와 제기하는 경우의 재결청·경유절차 및 청구기간을 기재(행정심판법 제42조 참조)
        ○제3자와 관련된 정보의 공개를 청구받은 행정기관이 공개여부에 관하여 제3자의 의견을 들은 경우에는, 당해 기관의 공개·비공개여부에 관한 결정 내용을 제3자에게도 통지하도록 함.
    마\. 처리기한
        ○공개·비공개 결정은 가능한 한 빠른 시일내에 처리하되, 최소한 당해 청구서를 접수한 날로부터 15일이내에 결정하도록 함.
        -청구받은 정보분량이 많거나 다른기관 또는 제3자(기관)와 관련된 정보로서 정보의 검색이나 의견수렴등으로 공개여부결정이 지연될 경우에는 그 사실과 함께 처리가능기한을 통지하도록 할 것
    바\. 정보의 공개
        (1) 공개일시 및 장소
        ○처리과에서 공개걸정통지서에 기재한 일시·장소에서 하되, 공개장소는 청구인의 편의를 고려하여 정하도록 함.
        ※공개장소는 당해 정보를 보관·보존하고 있는 부서·기관으로 함.
        (2) 공개방법
        ○정보공개는 당해 기록물의 원본을 직접 열람·복사형태로 공개하는 것을 원칙으로 함.
        -다만, 원본을 공개함으로서 당해 기록물이 오손·파손되거나 당해 정보중 일부분만을 공개하여야 할 때 기타 상당한 이유가 있을 때는 원본을 복사한 사본을 열람하게 할 수 있음.
        -기록물을 마이크로필름이나 광디스크에 의하여 보존하고 있는 경우에ㅐ는 열람용 마이크로필름 또는 광디스크에 의하여 공개할 수 있음.
