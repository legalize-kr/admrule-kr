# 통계작성의 승인(협의) 고시(천안시아동복지통계)

  1\. 통계의 명칭 : 천안시아동복지통계

  2\. 통계작성기관의 명칭 : 충청남도 천안시

  3\. 통계작성승인(협의)번호 [작성승인(협의)일] : 제691007호 [2022.05.17.]

  4\. 통계작성의 목적 : 천안시 아동복지  관련 정책수립에 필요한 기초자료  제공

  5\. 통계작성의 대상
    - 대상 : 개인
    - 모집단 : 천안시 주민등록이 되어있는 0~18세미만 아동
    - 대상 범위 및 규모 : 천안시 주민등록이 되어있는 0~18세미만 아동(외국인 제외)
    - 대상지역 : 동읍면

  6\. 통계작성의 주기 : 2년

  7\. 통계작성의 방법 : 가공통계/일반통계
