# 통계자료 제공비용 산정기준

  1\. 자료이용료
 자료이용료 = 기본료(20,000원/1MB) ＋ 추가비용(1,500 ×1MB 초과 MB당)

- 출력용량 1MB까지는 20,000원
- 1MB를 초과하는 용량은 1MB당 1,500원씩 추가 부과
※ On-site Access 자료 제공 시 이용환경 설정, 시스템 이용 등에대한 수수료로 자료이용료의 10%를 추가 징수

  2\. 소프트웨어개발비
   정보통신부 고시 제2005-22호
                     "소프트웨어사업대가의 기준"을 준용하여 징수

- 소프트웨어개발비는 주문형 위탁처리 요청 시 징수
