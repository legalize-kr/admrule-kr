# 수요물자대금 대지급 운영기준

조달사업법 시행령 제12조의 수요물자대금 지급방법과 관련하여 다음과 같이 대지급 세부기준을 정하여 운용한다.

**①** 수요물자대금의 지급방법은 수요기관 직접 지급을 원칙으로 한다. 다만 다음 각호에 해당되는 경우에 예외적으로 조달청장이 대신 지급할 수 있다.

  1\. 재해복구사업 등 긴급사업으로서 대지급에 의하지 않을 경우 사업수행에 지장이 있어 수요기관의 장이 대지급을 요청할 때
  2\. 중소기업으로 선금이나 네트워크론으로 생산 활동을 지원할 필요가 있어 수요기관의 장이 대지급을 요청하거나 조달청장에게 선금이나 네트워크론을 직접 신청할 때
  3\. 단가계약(제3자 단가계약, 다수공급자 계약(MAS) 포함)물품으로 수요기관의 장이 조달청장에게 대지급 요청할 때
     (단서 : 삭제. '09. 4. 6)
  4\. 군부대 또는 교통, 통신 등 기타 요인으로 조달업체의 접근이 극히 제한되는 수요기관의 경우로서 대지급의 필요성이 인정될 때
  5\. 대금지급 시점에 재해, 통신두절 등 불가피한 사정으로 인하여 직접 지급이 곤란한 경우로서 당해 수요기관의 장이 대지급으로 계약내용 변경을 요청할 때
  6\. 조달사업 수요기관 기준(조달청 고시 제2007 - 21호) 제3항의 대금선납기관(사회복지법인, 공익법인 등)에 납품한 대금(신설. ‘09. 4. 6)

**②** (삭제. ‘09. 4. 6)

**③** 제1항 제2호에 의하여 조달특별회계 회전자금으로 선금을 지급하는 경우에는 수요기관에 당해 금액을 고지하여 수납한다.

**④** (삭제. ‘09. 4. 6)

**⑤** 조달청의 수요물자 대지급 자금이 부족하여 납품대금을 바로 지급할 수 없는 경우에는 관련 법령이 정한 기한인 대금 청구 후  7일 이내에 지급할 수 있다.

**⑥** 이 기준은 2009. 4. 6일 조달요청분부터 적용한다.
