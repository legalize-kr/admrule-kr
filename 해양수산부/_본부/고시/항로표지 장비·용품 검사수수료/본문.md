# 항로표지 장비·용품 검사수수료

◎ 소형급 등명기 검사수수료
(단위:원/1대당 검사료)
<img id="13851035">
</img>
 1) 색도검사와 수직·수평발산각검사는 점멸식인 경우 검사수수료이며 회전식인 경우 1면당 검사 시 소요 검사수수료입니다.
 2) 등질검사와 유효광도검사의 경우 1종류 검사 시 소요 검사수수료입니다.
 3) 검사기본료는 검사항목 3종류 또는 동일항목 3회 이상 검사 시 적용합니다.

◎ 소형급 등명기 내환경 검사수수료(신설)
(단위:원/1대당 검사료)
<img id="13851036">
</img>
 1) 검사기본료는 기존의 등명기 검사기본료(51,100원, 부가세포함)를 적용합니다.
 2) 내환경 검사를 광학적, 전기적특성 검사와 병행하여 신청할 경우에는 검사기본료는 이중으로 부과하지 않습니다.
 3) 내환경 검사는 표본검사(검사대상 수량의 5% / 20대 미만은 1대) 방법으로 실시합니다.

</img>

 2) 검사기본료는 검사항목 3종류 또는 동일항목 3회 이상 검사 시 적용합니다.

◎ 충방전조절기 검사수수료(신설)
(단위:원/1대당 검사료)
<img id="13851070">
</img>
 1) 검사 기본료는 기존 등명기 검사 기본료(51,100원, 부가세포함)를 적용합니다.
 2) 내환경 검사를 전기적 특성 검사와 병행하여 신청할 경우 검사 기본료는 이중으로 부과하지 않습니다.
