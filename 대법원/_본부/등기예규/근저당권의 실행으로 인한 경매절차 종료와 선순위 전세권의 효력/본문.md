# 근저당권의 실행으로 인한 경매절차 종료와 선순위 전세권의 효력

근저당권이 실행되어 경매절차가 종료되었다 하더라도 근저당권보다 먼저 등기된  전세권등기에는 아무런 소장이 없다.
( 72.3.28.선고71다889판결)
