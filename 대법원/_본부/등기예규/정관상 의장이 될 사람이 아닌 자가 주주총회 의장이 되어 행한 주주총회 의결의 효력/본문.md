# 정관상 의장이 될 사람이 아닌 자가 주주총회 의장이 되어 행한 주주총회 의결의 효력

정관상 의장이 될 사람이 아닌 자가 정당한 사유없이 주주총회의 의장이 되어 의사에 관여하였더라도 그 주주총회에서의 결의가 부존재한 것으로는 볼 수 없다.
( 77.9.28.선고76다2386판결)
