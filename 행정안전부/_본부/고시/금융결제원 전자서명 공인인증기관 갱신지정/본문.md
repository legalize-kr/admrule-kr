# 금융결제원 전자서명 공인인증기관 갱신지정

전자서명법 시행령 제3조의3제4항 및 동법 시행규칙 제4조의2

○ 지정번호 : 제2010-4호

○ 기 관 명 : 금융결제원

○ 주    소 : 서울 강남구 역삼동 717

○ 대 표 자 : 김수명

○ 제공역무 : 정관상 사업범위 내에서의 공인인증 업무
○ 지정조건 : 전자서명법 제4조 제4항에 의한 제공역무의 구분지정에도 불구하고 2006. 7. 1 이전의 범용 공인인증서 가입자에 대하여는 차기 갱신 지정일인 2013. 4. 11까지 가입자의 요청이 있는 경우에는 범용공인인증서 이용을 보장하여야 함

○ 최초지정일 : 2000. 4. 12

○ 갱신지정일 : 2010. 4. 9

○ 지정 유효기간 : 2010. 4. 12 ～ 2013. 4. 11(3년)
