# 공공데이터 개방 표준

  1\. 목    적
 ○ 공공데이터 제공 및 이용을 활성화하기 위하여 공공데이터 개방 시 적용하기 위한 공통 개방 기준과 데이터셋 분야별 개방 기준(제공항목, 속성정보, 제공형식 등) 및 기타 데이터 개방 표준을 정의함

  2\. 적용대상 : 행정기관 및 공공기관

  3\. 용어정의
 ○ 공공기관 : 국가기관, 지방자치단체 및 「국가정보화 기본법」 제3조제10호에 따른 공공기관
 ○ 공공데이터 : 데이터베이스, 전자화된 파일 등 공공기관이 법령 등에서 정하는 목적을 위하여 생성 또는 취득하여 관리하고 있는 광(光) 또는 전자적 방식으로 처리된 자료 또는 정보
 ○ 기계 판독이 가능한 형태 : 소프트웨어로 데이터의 개별내용 또는 내부구조를 확인하거나 수정, 변환, 추출 등 가공할 수 있는 상태
 ○ 데이터셋 : 공공데이터 분야별 데이터의 집합
      * 주차장, 도시공원, 약국, 병의원 등 각 분야별 데이터의 집합을 말함
 ○ 개방 : 공공기관이 이용자에게 정보를 재활용할 수 있도록 제공하고, 제공받은 정보를 상업적·비영리적으로 이용할 권한을 부여하는 것
 ○ 제공 : 공공기관이 이용자로 하여금 기계판독이 가능한 형태의 공공데이터에 접근할 수 있게 하거나 이를 다양한 방식으로 전달하는 것
 ○ 오픈API(Open Application Programming interface, Open-API) : 공공기관 제공 정보를 민간에서 앱 개발 등에 바로 활용 가능토록 하는 공유프로그램의 표준 인터페이스

  4\. 공통 개방 기준
    가\. 표준용어 : 행정표준용어 준수
    나\. 제공방식
  1) 데이터 다운로드
   ○ 파일형식 : CSV, JSON, XML 등
     - 특정 S/W에 종속되지 않는 오픈 포맷형식으로 제공
   ○ 데이터파일 명명규칙 : 제공기관명_데이터셋명_기준일자.파일형식
       * 예 : 서울특별시_주차장정보_20140501.CSV
<img id="25775273">
</img>
  2) 오픈API
   ○ ‘데이터셋 분야별 개방 기준‘에 제시된 제공항목을 반영하여 항목별 속성정보를 준수하여 데이터를 제공할 수 있도록 지원
    다\. 제공경로 : 공공데이터포털(www.data.go.kr)
   ○ 사용자가 공공데이터포털에서 직접 데이터를 다운로드하거나 오픈API를 신청하여 사용할 수 있도록 제공

  5\. 데이터셋 분야별 개방 기준(제공항목 및 항목별 속성정보)
