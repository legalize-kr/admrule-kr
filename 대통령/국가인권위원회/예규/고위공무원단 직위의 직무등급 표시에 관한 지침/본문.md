# 고위공무원단 직위의 직무등급 표시에 관한 지침

  1\. 직무분석규정 제10조제2항 규정에 의하여 고위공무원단 직위의 직무등급을 다음과 같이 표시한다.
    가\. 사무총장 : 가 등급
    나\. 인권정책본부장 : 다 등급
    다\. 행정기획본부장 : 다 등급
    라\. 침해구제본부장 : 다 등급
    마\. 차별시정본부장 : 다 등급
    바\. 인권교육본부장 : 라 등급

  2\. 이 예규는 2006년 8월 22일부터 시행한다.
