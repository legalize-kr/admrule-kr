# 2004년도 수요관리투자계획 수립지침

  1\. 개   요

  □ 수요관리투자계획 수립 대상자
   0 한국가스공사, 한국지역난방공사
  □ 투자계획 및 시행결과 제출기한
   0 투자계획 : 2004년2월10일
   0 시행결과 : 2004년2월28일
    ※ 반기별 시행결과는 2004년 수요관리투자계획 확정 통보 후 6월간의 시행결과를 익월 말까지 제출
  □ 투자계획에 포함할 사항
   0 장?단기 에너지 수요전망(요약)
   0 수요관리사업의 목표 및 달성방법
   0 주요 사업별 투자비 규모
   0 기타 에너지절약 잠재량 산출 등 수요관리 관련사항
  2\. 작성 기본원칙

  □ 수요관리투자계획을 장기에너지수급계획과 연계하여 작성하되 총투자비는 2002년 총매출액의 1% 수준으로 수립
  □ 수요관리전문기관에 대한 출연금규모는 관련기관과 협의 후 책정
  □ 전년도 사업중 미착수한 사업은 금년도 계획에 추가하여 반영

  3\. 주요 사업비 산정기준

  □ 총투자비
   0 2004년도 수요관리 총투자비는 2002년도 총매출액대비 1%수준으로 산정
  □ 가스냉방기기 등 설치지원비
   0 가스냉방기기 등 설치지원비는 전년대비 총투자비 증가율을    반영하여 책정
   0 가스냉방기기 설치지원비 산정기준
     - 2003(계획)가스냉방기기 설치지원비×(1+2004년도 총투자비 증가율)
  □ 수요관리전문기관 출연
   0 수요관리전문기관에 대한 출연금은 예년의 출연금규모 및 2004년도 총투자비 증가율을 감안하여 수요관리전문기관과 사전 협의하여 책정

  4\. 수요관리투자계획서 작성 세부항목

  □ 총 괄
   0 중장기 및 2004년도 수요예측
   0 수요관리 투자비 요약
    - 분야별 투자계획 구분에 따른 세부내역(첨부 양식)
   0 주요 사업별 수요관리 목표량

  □ 분야별 세부투자계획
   0 에너지절약 및 효율향상 분야
   0 부하관리 분야
   0 부하유지, 부하창출, 연료대체 분야
   0 수요관리전문기관 출연 등 기타

  5\. 2003년도 시행결과 분석 및 평가

  □ 에너지공급사(한국가스공사, 한국지역난방공사)는 2003년도 투자사업의 계획대비 평가결과 분석 및 산출근거(비용 및 절감량 등)를 수요관리전문기관에 2004년 2월28일까지 제출

  □ 수요관리전문기관은 6인 이상의 관계 전문가로 구성된 평가위원회를 구성, 에너지공급사가 제출한 평가서를 종합적으로 평가 후 산업자원부에 보고

  6\. 기타사항

  □ 제출된 수요관리투자계획서의 수정?보완 요청시 요청일로 부터 30일 이내에 수정된 투자계획을 제출하여야 함.

  □ 투자계획을 변경할 경우에는 사전 협의하여야 하며, 투자계획의 시행실적이 계획대비 부진시에는 그 사유와 대책을 명기하여야 함.

  □ 수요관리전문기관은 2004년도 수요관리투자계획 검토보고서를 2004년 2월 28일까지, 2003년도 투자사업 시행결과 평가보고서를 2004년 3월 31일까지 제출하여야 함.
