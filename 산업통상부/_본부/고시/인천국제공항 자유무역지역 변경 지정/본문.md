# 인천국제공항 자유무역지역 변경 지정

**①** 명칭 : 인천국제공항 자유무역지역

**②** 위치 : 인천광역시 중구 운서동 일원

**③** 경계 : 인천국제공항 화물터미널 지역, 1단계와 2단계 공항물류단지 외곽 울타리

**④** 면적 : 3,049,129㎡ (당초 : 3,049,891㎡)
