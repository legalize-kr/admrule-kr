# 수질오염물질 배출허용기준 중 별도배출허용기준 지정·고시(음성 대풍산업단지)

대풍산업단지 내 배출시설에서 배출되는 폐수를 배수설비를 통하여 대풍산업단지 공공폐수처리시설에 전량 유입하는 경우에는, 해당 배출시설에서 배출되는 수질오염물질의 배출허용기준을 다음과 같이 정한다.

  ※ 2001.3.1. 이전에 설치된 폐수배출시설은 별도배출허용기준
