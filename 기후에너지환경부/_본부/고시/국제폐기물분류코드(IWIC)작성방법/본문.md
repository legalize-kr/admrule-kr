# 국제폐기물분류코드(IWIC)작성방법

  1\. 폐기물의국가간이동및그처리에관한법률시행령 별지 제1호서식 폐기물 수출허가(변경허가)신청서?별지 제4호서식 폐기물 수입허가(변경허가)신청서중 9란 처리/재생처리공정?14란 물리적 특성?18란 H번호?19란 UN등급 및 별지 제5호서식 수입이동서류중 6란 처리/재생처리공정?8란 물리적 특성?13란 UN등급은 다음과 같이 작성한다.
    가\. 별지 제1호서식 폐기물 수출허가(변경허가)신청서?별지 제4호서식 폐기물 수입허가(변경허가)신청서중 9란 처리/재생처리공정 및  별지 제5호서식 수입이동서류중 6란 처리/재생처리공정은 ‘서식에 사용되는 약어 목록’ 및 ‘목록 2 폐기물의 처리방법’을 참조하여 해당번호를 기입한다.
    나\. 별지 제1호서식 폐기물 수출허가(변경허가)신청서?별지 제4호서식 폐기물 수입허가(변경허가)신청서중 14란 물리적 특성 및  별지 제5호서식 수입이동서류중 8란 물리적 특성은 ‘서식에 사용되는 약어 목록’을 참조하여 해당번호를 기입한다.
    다\. 별지 제1호서식 폐기물 수출허가(변경허가)신청서?별지 제4호서식 폐기물 수입허가(변경허가)신청서중 18란 H번호은 ‘서식에 사용되는 약어 목록’ 및 ‘목록 5 폐기물의 잠재적 유해성’을 참조하여 해당번호를 기입한다.
    라\. 별지 제1호서식 폐기물 수출허가(변경허가)신청서?별지 제4호서식 폐기물 수입허가(변경허가)신청서중 19란 UN등급 및  별지 제5호서식 수입이동서류중 13란 UN등급은 ‘서식에 사용되는 약어 목록’을 참조하여 해당번호를 기입한다.
  2\. 폐기물의국가간이동및그처리에관한법률시행령 별지 제1호서식 폐기물 수출허가(변경허가)신청서?별지 제2호서식 수출이동서류?별지 제4호서식 폐기물 수입허가(변경허가)신청서중 15란 및 별지 제5호서식 수입이동서류중 9란은 다음과 같이 작성한다.
    가\. 목록 1에서 폐기물을 처리하고자 하는 사유별로 하나 또는 최대 두 가지를 선택하여, 코드 번호를 ‘Q...’로 기입한다.
     (Choose the one or at most two major reason(s) why the wastes are intended for disposal from the list in Table 1. Mark down the reason(s) as Q...plus the code number(s).)
    나\. 목록 2에서 폐기물의 향후 처리방법별로 가장 근접한 한 가지 과정을 선택하여, ‘D... 또는 R...’로 기입한다.
     (Indicate the method which has been selected for disposal of the wastes by choosing the one operation from Table 2 which most closely describes the fate intended for the wastes. Mark down as D...or R... .plus the code number from Table 2.A or Table 2.B as appropriate.)
    다\. 목록 3에서 폐기물의 성상 및 발생공정별로 가장 근접하는 항목을 선택하여, 폐기물의 성상과 코드번호를 ‘L..., P..., S...’로 기입한다. 폐기물의 성상이 액체의 경우는 L, 슬러지(반고상)의 경우는 P, 고체의 경우는 S(분말은 고체로 간주함)로 기입한다.
     (Select from Table 3, the one descriptor which most closely describes the generic form of the wastes. Mark down this descriptor as L..., P.. or S... Plus the code number. Decide whether the wastes are liquid (L), sludge (P) or solid (S). Powders are considered to be solids.)
    라\. 목록 4에서 잠재적인 유해폐기물의 성분을 검토하여 해당성분이 없으면 “CO"로 기입하고, 해당성분이 한가지인 경우 해당 코드 번호를 ‘C...'로 기입한다. 해당성분이 한가지 이상인 경우에는 당해 폐기물에 포함된  3개 이하의 성분에 대한 유해성 최적추정치에 따라 그 유해성이 높은 순서를 내림차순으로 코드 번호를 ‘C...'로 기입한다.
     (Examine Table 4; either the wastes do or do not contain one or more of the constituents listed. If none, mark down as code??CO??. If one, mark down the appropriate code number. If more than one, then the best estimate for the group of no more than three entries in terms of descending hazard should be made. This estimate is meant to be qualitative and based upon the best judgment of the generator of the wastes; physical testing is not implied.)
    마\. 목록 5에서 폐기물의 잠재적 유해성을 가장 잘 나타내는 한 가지 또는 두 가지 항목을 선택하여, 코드 번호를 ‘H...’로 기입한다.
     (Select from Table 5 the one or at most two major potential hazard(s) presented by the wastes.  Mark down as H...Plus the code number(s).)
    바\. 목록 6에서 잠재적으로 유해한 폐기물 발생산업 한 가지를 선택하여 코드 번호를 ‘A...'로 기입한다.
     (Select from Table 6 the most appropriate single activity generating the wastes. Mark down as A...Plus the code number.)
    사\. 국제폐기물분류코드(IWIC)의 기재순서는 목록1 내지 목록6까지의 순서에 의한다. 코드 번호사이는 이중 사선으로 구분하며, 목록에서 한가지 이상의 코드 번호가 있을 경우에는 각 코드 번호사이에 플러스 (+) 부호를 사용하여 기입한다.
     (The order of the International Waste Identification Code is the same as Tables 1 through 6. Main heads of the coding system are set off by double oblique lines. Where more than one entry from a specific Table is applicable, the plus sign(+) is used to separate the codes for each such entry:)
