# 신기술 유효기간 연장 심사평가 결과[(주)포스코건설]

  1\. 기술명 : 하수슬러지와 스텐레스분화슬래그를 혼합하여 열풍회전 3PASS 건조장치와 양생SILO를 이용한 시멘트 원료화 기술
    가\. 기술 보유자
  1) 성 명 : (주)포스코건설
  2) 법인등록번호 : 174611-0******
  3) 소재지 : 경상북도 포항시 남구 괴동동 568-1
  4) 전화번호 : 031-370-9827
    나\. 신기술 인증
  1) 인증서 발급번호 : 제69호
  2) 기술의 개요
     ○ 하수슬러지에 스텐레스분화슬래그, Al2(SO4)3, CaO를 혼합하고 3PASS 건조장치를 이용 열풍회전 방식으로 건조시키고 상향류식 공기 주입 양생Silo에서 건조·고형화 처리 후 시멘트 원료로 사용하는 기술
     ※ 공정구성 : 슬러지·슬래그·Al2(SO4)3·CaO 호퍼 → 혼합·파쇄 → 3PASS건조기 → 로타리 스크린 → 양생 Silo → 배출
  3) 신기술 범위
     ○ 하수슬러지에 스텐레스분화슬래그, Al2(SO4)3, CaO를 혼합하고 열풍 회전방식인 3PASS 건조장치와 상향류식 공기주입 양생Silo를 이용하여 건조·고형화 처리 후 시멘트 원료로 재활용하는 기술
  4) 신기술의 유효기간 : 2003. 7.25. ～ 2008. 7.24.

  2\. 위 신기술에 대한 환경기술평가 결과는 환경신기술 정보시스템(www.koetv.or.kr)에 게시되어 있으며, 기타 상세한 사항은 한국환경기술진흥원 환경신기술평가단(☏ 02-3800-582~584)에 문의하시기 바랍니다.
